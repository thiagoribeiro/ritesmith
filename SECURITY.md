# Security Policy

## Reporting a vulnerability

Please **do not** open a GitHub issue for security vulnerabilities.

Report vulnerabilities by email to the maintainer listed in `pyproject.toml`. Include:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- Affected versions (if known)

You can expect an acknowledgment within 72 hours and a resolution timeline within 14 days for confirmed issues.

## Scope

In-scope: the RiteSmith server itself (API, Lua sandbox, policy engine, MCP endpoint).

Out-of-scope: third-party dependencies, your own deployment infrastructure, or issues that require physical access to the host.

## Disclosure policy

We follow coordinated disclosure. We ask that you give us a reasonable window to patch before publishing details publicly.
